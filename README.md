# МиниИгры — образовательная платформа

Веб-приложение на FastAPI для создания и прохождения мини-игр (текстовые вопросы, изображения, аудио).  
Поддерживает регистрацию пользователей, админ-панель для управления категориями, подкатегориями, играми и пользователями, а также отслеживание прогресса.

## Требования

- Python 3.9+
- PostgreSQL 12+ (должен быть запущен)
- pip

## Установка и запуск

### 1. Клонируйте репозиторий

```bash
git clone https://github.com/your-username/minigames.git
cd minigames
```

### 2. Создайте виртуальное окружение и установите зависимости

```bash
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/MacOS:
source venv/bin/activate

pip install -r requirements.txt
```

### 3. Настройте базу данных

Создайте базу данных PostgreSQL с именем `minigames_db`.  
Убедитесь, что сервер PostgreSQL доступен на `localhost:5433`, пользователь `postgres` с паролем `12345` (данные из `main.py`).  
Вы можете изменить параметры подключения в коде `main.py` (строка `SQLALCHEMY_DATABASE_URL`).

Пример создания базы через `psql`:

```sql
CREATE DATABASE minigames_db;
```

Таблицы будут созданы автоматически при первом запуске приложения.

### 4. Запустите приложение

```bash
python main.py
```

Приложение будет доступно по адресу [http://127.0.0.1:8001](http://127.0.0.1:8001).

### 5. Дополнительно: запуск тестов

Если в проекте присутствуют тесты (например, `test_password_utils.py`), выполните:

```bash
pytest
```

## Структура проекта

- `main.py` – основной файл FastAPI (роуты, модели БД, утилиты)
- `templates/` – Jinja2 шаблоны страниц
- `static/` – CSS и JavaScript (игровой движок `engine.js`)
- `uploads/` – папка для загруженных изображений и аудио (создаётся автоматически)

## Примечания

- Для загрузки файлов требуются папки `uploads/images` и `uploads/audio` – они создаются автоматически при старте.
- По умолчанию приложение использует порт 8001, изменить его можно в блоке `if __name__ == "__main__"`.
